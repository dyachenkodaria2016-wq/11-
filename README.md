# Assets

Папка зарезервована для зображень, іконок або прикладів, які вчитель вирішить додати до уроку.

Не додавайте до репозиторію фотографії учнів чи інші персональні дані без належної згоди. Для навчальних прикладів використовуйте власні матеріали або зображення з відповідною ліцензією та зазначайте авторство.
